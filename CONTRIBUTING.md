### Quick Setup (3 Steps)

1. **Authenticate in VS Code**
   - Open Command Palette: `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (Mac)
   - Type: `GitHub: Sign In`
   - Complete GitHub authentication
   - Restart VS Code

2. **Enable Copilot Features**
   - Open Settings: `Ctrl+,`
   - Search: `copilot`
   - Enable: "Copilot: Enable Copilot"
   - Enable: "Copilot: Allow Edits"

3. **Verify Integration Works**
   - Open Copilot Chat: `Ctrl+Shift+Alt+I`
   - Try: `/explain` on any code
   - If it works without errors → ✅ Ready!
