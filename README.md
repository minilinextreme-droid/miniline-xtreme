# MiniLine Xtreme 🏎️

Marketplace de miniaturas Hot Wheels — 100% funcional no **GitHub Pages**.

## Como publicar em 2 minutos

1. Crie uma conta grátis em https://github.com (se ainda não tiver)
2. Clique em **+ → New repository**
   - Nome: `miniline-xtreme` (ou o que quiser)
   - Marque **Public** → **Create repository**
3. Clique em **uploading an existing file** e arraste TODOS os arquivos
   deste zip (descompactados, com o index.html solto na raiz — não dentro
   de pasta)
4. Role até embaixo → **Commit changes**
5. Vá em **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / pasta: **/ (root)** → **Save**
6. Em 1-2 minutos o site estará no ar em:
   `https://SEU-USUARIO.github.io/miniline-xtreme/`

## Recursos

- Catálogo, carrinho, checkout com frete por CEP e cupons
- Sistema de vendedor com aprovação do admin
- Avaliações com estrelas, ofertas relâmpago, chat com vendedor
- Painel admin completo (métricas, pedidos, repasses, lotes)
- Login com Google (veja REAL-SETUP.md)

## Importante

- **Admin:** a conta com e-mail `minilinextreme@gmail.com` vira admin
  automaticamente. Cadastre-se com esse e-mail para ter o painel.
- Cada visitante usa os dados do próprio navegador (modo local). Para
  sincronizar produtos, pedidos e contas entre todos os visitantes
  (modo "site de verdade" com banco de dados), siga o **REAL-SETUP.md** —
  é grátis com o Supabase.
- Pagamentos com cartão: **STRIPE-SETUP.md** · Repasses aos vendedores:
  **PAGAMENTOS-VENDEDORES.md**
